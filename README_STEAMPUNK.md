# 村川たくと公式サイト ― CLOCKWORK SADO（スチームパンク版・試作01）

作成日：2026-10-27。現在編集中の**Ver.1.30**を元にした、別デザインの実働Webサイトです。**元のVer.1.30は変更していません。**

## すぐ見る

- `LOCAL_PREVIEW/index.html` をブラウザで開いてください。公開せずにPCから確認できます。
- ページ内のナビゲーション、カード、SNSリンク、議会記録の展開、ゲームなどを操作できます。外部SNS・YouTube・議会資料へのリンクはインターネット接続が必要です。
- PC・スマートフォン両対応。動作環境は主要な最新ブラウザです。

## どこを変えたか

- ヘッダー・ナビ：真鍮と青黒い金属調のUI、計器の意匠
- トップ：現行の本人写真そのまま、ホログラム風発光、円形計器、政策・議会などの4つの案内カード
- 下層ページ：紙面を読みやすくするため明るい羊皮紙色の情報カードを組み合わせる
- アニメーション：ゆっくり回る計器、ホバー時の微細な動き。OSの「視差効果を減らす」に対応

**変えていないもの**：プロフィール／政策・理念の文案、これまでの一般質問データ（62論点）、2026年9月以降のレポート、元写真、SNS・動画リンク、自作ゲーム本体、連絡先。

## 公開データと再生成

- `_dist/`：公開用に生成済みのファイル一式（公開先のドキュメントルートに置く）。
- `LOCAL_PREVIEW/`：ブラウザでローカル表示できる別コピー。
- `build.py`：元サイトVer.1.30の静的サイト生成器。
- `build_steampunk.py`：元データでサイトをビルドした後、スチームパンク用CSSとトップの導線を追加する生成器。
- `assets/steampunk.css`：新テーマの主な編集先。元の `assets/site.css` に上書きせず読み込む方式。
- `assets/clockwork-dial.svg`：装飾用の自作計器SVG。
- `content/`：元の掲載データ（変更なし）。

再生成（Python 3、追加パッケージ不要）：

```bash
python build_steampunk.py
```

GitHub Pages等でサブパスに公開する場合：

```bash
python build_steampunk.py --base-path REPOSITORY --site-url https://USERNAME.github.io
```

元の `build.py` **だけ**を実行するとテーマを追加しない通常版が `_dist` に再生成されます。必ず `build_steampunk.py` で更新してください。
